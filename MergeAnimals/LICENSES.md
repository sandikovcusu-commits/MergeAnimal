# Lisenziyalar və istifadə

Bu repository üçün müəllif və layihə kodunun yayım lisenziyası istifadəçi tərəfindən ayrıca seçilməyib; icazəsiz açıq mənbə lisenziyası təyin edilmir. Godot Engine öz MIT lisenziyası ilə ayrıca paylanır. Aktivlərin mənşəyi və kommersiya auditinin statusu üçün `ASSET_LICENSES.md`-ə baxın.
