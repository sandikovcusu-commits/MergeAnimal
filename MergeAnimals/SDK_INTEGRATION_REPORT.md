# V0.8.2 — CrazyGames SDK inteqrasiyası: WIP, tamamlanmayıb

## Faktiki vəziyyət

Baza `737389d`. CrazyGames-in rəsmi Godot Asset Store səhifəsində `v2.0.0` (21.10.2026) kimi verilən Godot 4 SDK arxivi CI-də birbaşa [rəsmi mənbədən](https://store.godotengine.org/asset/crazygames/crazysdk/download/7510/) alınıb: SHA-256 `b5c5450a8b645966a6368e8c5c99dd7e00729e517e7de25dc7b6cc2245993e95`. Rəsmi MIT lisenziyası `addons/crazygames/LICENSE`-dədir. Paket metadatasındakı versiya 2.0.0, öz `plugin.cfg` versiyası 1.0.0, `CrazyGames.gd`-də ötürülən wrapper versiyası 1.0.1-dir; bunlar eyni şey kimi təqdim edilmir. SDK uzaqdan yüklənən HTML5 v3 skriptindən istifadə edir; CI local mühitinin konsolunda runtime 3.8.0 bildirildi, CDN URL versiyanı dəqiq pinləmir.

Addon `res://addons/crazygames` altında saxlanır, autoload-lar əl ilə qeydiyyatdadır. İki kiçik yerli patch yalnız `crazygames` Web feature ilə işə salınmağı və skript/initialization xətalarının təhlükəsiz qarşılanmasını təmin edir; native və adi Web export SDK-nı yükləmir. `Web CrazyGames (experimental)` export preset-i SDK-nı aktivləşdirir. `AdManager` 8 saniyə initialization limiti, local/unavailable fallback və idempotent gameplay start/stop saxlayır. Pause/Resume, Game Over və Challenge nəticəsinə əsas hadisələr qoşulub. `muteAudio` platform tələbi Master mute-a üstün tutulur; Web JavaScript boolean-to-integer çevrilməsi nəzərə alınıb. İstifadəçi mute ayarı ayrıca qorunur. Yükləmə hadisələri rəsmi Godot sənədinə görə lazım deyil; Godot export loading-i idarə edir. Happy Time hələ inteqrasiya edilməyib.

**Əsas məhdudiyyət: bu, tamamlanmış reklam inteqrasiyası deyil.** `AdManager.rewarded_available()` həmişə false qaytarır; yalnız Local/No Ads işləyir. CrazyGames reklam provider-i, üç rewarded təklifi və ad request/callback state machine, transaction ID, timeout, duplicate/late qorunması, mükafat checkpoint-i və uyğun UI hələ həyata keçirilməyib. Ona görə reklam düymələri göstərilmir və bu build gəlir gətirmir. Mövcud `RewardRequestGateway` təkbaşına mükafat vermir. Rəsmi addon-un mövcud global ad callback-ləri transaction ID daşımır; onları sessiyalararası təhlükəsiz mükafat callback-i kimi birbaşa istifadə etmək olmaz. Bu WIP-i monetizasiya hazır məhsul kimi istifadə etməyin.

## Rəsmi qaydalar və edilməli işlər

Yoxlanmış sənədlər: [SDK intro](https://docs.crazygames.com/sdk/intro/), [video ads](https://docs.crazygames.com/sdk/video-ads/), [ad requirements](https://docs.crazygames.com/requirements/ads/), [technical](https://docs.crazygames.com/requirements/technical/), [Basic Launch metrics](https://docs.crazygames.com/resources/basic-launch-metrics/), [game events](https://docs.crazygames.com/sdk/game/). Basic Launch zamanı reklamlar deaktivdir; işə yaramayan rewarded düymələri göstərilməməlidir. Reward düyməsi aktiv gameplay ekranında olmamalı, könüllü və aydın olmalı, reklamsız alternativ təmin olunmalıdır. Request zamanı oyun/input bloklanmalı, səs isə yalnız `adStarted` zamanı susdurulmalıdır; `adFinished`-dən başqa heç bir nəticə reward sayılmamalıdır.

Növbəti iş: sessiyaya bağlı unikal transaction-lar və təhlükəsiz timeout/ləğv; yalnız rəsmi callback-dən sonra Undo/Remove/Rescue mükafatının limitlə birlikdə mövcud power-up checkpoint-də commit edilməsi; Challenge bloklanması; könüllü uyğun UI; sonra hər iki brauzerdə mock, rəsmi localhost demo və (ayrıca icazə ilə) platforma preview sınaqları. Save failure, refresh/Continue/backup/restart və IndexedDB async son-yazı riski ayrıca yoxlanmalıdır. İndiki testlər bu tələbləri sübut etmir. Heç bir hesab yaradılmayıb, heç nə yayımlanmayıb, ödəniş və ya main merge edilməyib.
