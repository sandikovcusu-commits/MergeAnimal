## Replacement designs
Twelve new geometric characters were authored from scratch in Agent-written source `tools/generate_animal_vectors.py`, not recolors or transformations of the legacy sprites. The editable SVG output is `art_source/vector_animals/*/normal.svg`; 512x512 alpha PNG output uses development-only resvg-js 2.6.2 via `tools/render_animal_vectors.cjs`. Reproduction requires Python 3, Node and @resvg/resvg-js@2.6.2. For example: `python3 tools/generate_animal_vectors.py`, then `npm install --prefix /tmp/animal-render @resvg/resvg-js@2.6.2`, `NODE_PATH=/tmp/animal-render/node_modules node tools/render_animal_vectors.cjs`. No legacy raster reference is input to these generators. This technical provenance is not a legal grant; status UNKNOWN pending applicable Arena terms and owner review. No promise of similarity clearance or non-infringement can be made from code inspection alone.
