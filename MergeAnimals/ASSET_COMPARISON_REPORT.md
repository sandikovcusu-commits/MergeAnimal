# Asset comparison — working draft

The 12 old runtime PNGs were replaced by newly authored vector artwork, rasterized to RGBA 512×512 at the same runtime paths; the existing 256-pixel import limit remains for mouse, hamster and rabbit. Animal IDs, physics radii, texture rectangle and game logic are unchanged. Editable SVGs and code are under `art_source/vector_animals/` and `tools/`. The old AI artwork is preserved only as historical source/provenance, not as runtime assets. See `COMMERCIAL_RIGHTS_REPORT.md` for unresolved rights.

A local raster-level check found no pixels with alpha > 8 outside the nominal 256-pixel radius disk for any of the new PNGs; the bottom alpha bounding box is y=506 for all 12 (six transparent pixels below, before rendering/import filtering). This does not prove contact under rotation, animation, on-device rendering, or acceptable appearance. The ears, mane and trunk are illustrative elements within the disk, rather than new physical protrusions. Actual Godot Web software-rendered Chromium screenshots are available in `artifacts/v0901/45965105627/qa/`; qualitative human design review and real-device verification remain outstanding. No actual device performance measurements are claimed. A locally composed review sheet is not a game screenshot.

Raw runtime PNG totals changed from 3,608,716 bytes in baseline `8895ddf` to 944,124 bytes (−73.8%); these are source file sizes, not Godot imported texture memory, PCK sizes, runtime performance or download transfer. Per-animal byte sizes, alpha bounding boxes and disk pixel counts are in `docs/asset_audit/sprite_measurements.csv`. The generated vector layout centers its nominal collision disk at (256,256); alpha bounds show that top/side whitespace can be appreciable, especially rabbit, dog and elephant. **Collision remains a perfect circle**, so contacts at some angles can still look separated; real rotated gameplay/visual approval is required. Bounding boxes alone do not prove visually convincing contact.

Internal non-game comparison sheet `artifacts/v0901/before-after-internal.png` uses legacy assets solely for audit, not clearance or distribution; it is not a screenshot. The separate `artifacts/v0901/vector-review.png` is a locally composed sprite sheet, also not a screenshot. Production export must not include either sheet, tests, old concepts or editable source folder.
