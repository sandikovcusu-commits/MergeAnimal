# Asset comparison — working draft

The 12 old runtime PNGs were replaced by newly authored vector artwork, rasterized to RGBA 512×512 at the same runtime paths; the existing 256-pixel import limit remains for mouse, hamster and rabbit. Animal IDs, physics radii, texture rectangle and game logic are unchanged. Editable SVGs and code are under `art_source/vector_animals/` and `tools/`. The old AI artwork is preserved only as historical source/provenance, not as runtime assets. See `COMMERCIAL_RIGHTS_REPORT.md` for unresolved rights.

A local raster-level check found no pixels with alpha > 8 outside the nominal 256-pixel radius disk for any of the new PNGs; the bottom alpha bounding box is y=506 for all 12 (six transparent pixels below, before rendering/import filtering). This does not prove contact under rotation, animation, on-device rendering, or acceptable appearance. The ears, mane and trunk are illustrative elements within the disk, rather than new physical protrusions. Screenshot review of an actual Godot runtime and a qualitative human design review are outstanding. No actual device performance measurements are claimed. A locally composed review sheet is not a game screenshot. Tests and PCK audit must be rerun against the changed files.
