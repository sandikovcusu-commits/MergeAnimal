# Model və alət auditi — Gün 4

Əlçatan alətlər: Arena kod agenti və Arena image generation aləti. Bu alətin cavabı vendor, dəqiq model adı/versiyası, istifadə şərtləri və parametr seçim API-si təqdim etmir. Claude Opus/Sonnet, GPT-6.2/Codex, OpenAI Image və Gemini modellərini ayrı-ayrılıqda çağırmaq üçün bu sessiyada doğrulanmış çıxışımız yoxdur; onlarla ayrıca iş görüldüyü iddia edilmir. Ödənişli xarici API inteqrasiyası və çağırışı edilməyib.

Rəsmi kataloqlar istifadə imkanının sübutu deyil: [OpenAI model kataloqu](https://platform.openai.com/docs/models) `gpt-image-2.6-sunburst`, `gpt-image-2.6-flare`, `gpt-image-2.5-sunburst` və `gpt-6.2-astra` adlarını göstərir; [Anthropic modelləri](https://docs.anthropic.com/en/docs/about-claude/models) Claude Opus 5.5 / Sonnet 5.5 göstərir; [Google image sənədi](https://ai.google.dev/gemini-api/docs/image-generation) Nano Banana model ailəsini təsvir edir. Açılan səhifədə model siyahısı qaytarılmadığı halda əvvəlki auditdə qeyd olunan adların bu gün aktual olmasını ayrıca təsdiqləmirik. Google və OpenAI şərtləri `ASSET_LICENSES.md`-dədir; konkret Arena çağırışına tətbiq olunan xidmət şərti müəyyən olunmayıb. Alət ilə generasiya edilmiş materiallar yalnız təcrübi DEV materialdır; kommersiya buraxılışı üçün BLOKLU-dur.

## V0.4.1 yoxlama
2026-11-25 rəsmi [OpenAI model kataloqu](https://developers.openai.com/api/docs/models) GPT Image ailəsini göstərir; [GPT-Image-2.5 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst) və [Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare) rəsmi model səhifələridir. Kataloq faktiki bu sessiyada həmin modelin seçilə bilməsini göstərmir: Arena aləti konkret model seçmək və model ID-ni almaq imkanı verməyib; Bear/Lion üçün faktiki model və vendor UNKNOWN. İki alət çağırışı uğurlu oldu; yeni limitin maksimumu məlum deyil. Əlavə birbaşa ödənişli API çağırılmadı. Xidmət şərtləri model kataloqundan ayrıdır; Arena üçün hüquq statusu ayrıca təsdiqlənməyib.
