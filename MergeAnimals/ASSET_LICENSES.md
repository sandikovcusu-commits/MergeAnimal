# Aktiv mənşəyi

Gün 1: kodla çəkilmiş müvəqqəti diaqnostik həndəsi fiqurlar və mətnlər bu layihə üçün yazılıb; üçüncü tərəf sprite, audio, şrift, model tərəfindən generasiya edilmiş şəkil və ya rəqib aktivləri daxil edilməyib. Bunlar yekun qrafika deyil. Godot mühərriki layihəyə daxil edilmir, mühərrikin öz MIT lisenziyası ayrıca tətbiq olunur: https://github.com/godotengine/godot/blob/4.7.2-stable/LICENSE.txt.

Kommersiya istifadəsinin yekun auditi edilməyib. Gələcək generasiya və üçüncü tərəf aktivləri üçün mənşə, müəllif/model, tarix, lisenziya və şərtlər burada ayrıca qeydə alınmalıdır. İstifadəçi tərəfindən sadalanan modellərə çıxış yoxlanmayıb və istifadə olunduğu iddia edilmir; bu mərhələdə ayrıca ödənişli API çağırışı edilməyib.

## Gün 3 konseptləri, 2026-11-25
`concepts/{mouse,cat,elephant}.png` Arena-nın görüntü generasiya aləti ilə bu layihə üçün ayrıca generasiya edilib. Alət nəticəsi faktiki model adı və ya vendor qaytarmadı; buna görə bu şəkillərin GPT-Image və ya Gemini ilə yaradıldığını iddia etmək olmaz. Rəsmi kataloqlar: [OpenAI image models](https://platform.openai.com/docs/models), [Google Gemini image generation](https://ai.google.dev/gemini-api/docs/image-generation). Bunlar alətin konkret backend-ini təsdiqləmir. Əlavə birbaşa ödənişli API çağırışı edilməyib.

Hər fayl 1254×1254 RGB və tam opakdır: damalı fon gerçək şəffaflıq deyil. Bunlar 512×512 şəffaf sprite tələbinə cavab verməyən üslub konseptləridir, oyun aktivlərinə inteqrasiya edilməyib. Modelin dəqiq adı və Arena xidmətinin konkret kommersiya lisenziya şərtləri alət nəticəsində göstərilmədiyindən kommersiya istifadəsi **təsdiqlənməyib**; istifadədən əvvəl xidmət müqaviləsi, üçüncü tərəf hüquqları və yerli qanun üzrə ayrıca yoxlama lazımdır. Eksklüzivlik və müəllif hüququ iddia edilmir.
