## Gün 3 konseptləri, 2026-11-25
`concepts/{mouse,cat,elephant}.png` Arena-nın görüntü generasiya aləti ilə bu layihə üçün ayrıca generasiya edilib. Alət nəticəsi faktiki model adı və ya vendor qaytarmadı; buna görə bu şəkillərin GPT-Image və ya Gemini ilə yaradıldığını iddia etmək olmaz. Rəsmi kataloqlar: [OpenAI image models](https://platform.openai.com/docs/models), [Google Gemini image generation](https://ai.google.dev/gemini-api/docs/image-generation). Bunlar alətin konkret backend-ini təsdiqləmir. Əlavə birbaşa ödənişli API çağırışı edilməyib.

Hər fayl 1254×1254 RGB və tam opakdır: damalı fon gerçək şəffaflıq deyil. Orijinallar 512×512 şəffaf deyil. `concepts/processed/` altında ImageMagick ilə damalı fon kənardan flood-fill təmizlənərək və 512×512 ölçüyə endirilərək alpha-kanallı törəmələr yaradılıb; vizual baxış aparılıb, kənarlarda və Mouse quyruğunun içində əl təmizliyi lazım ola bilər. Bu törəmələr də yalnız ilkin üslub konseptləridir və oyun aktivlərinə inteqrasiya edilməyib. Modelin dəqiq adı və Arena xidmətinin konkret kommersiya lisenziya şərtləri alət nəticəsində göstərilmədiyindən kommersiya istifadəsi **təsdiqlənməyib**; istifadədən əvvəl xidmət müqaviləsi, üçüncü tərəf hüquqları və yerli qanun üzrə ayrıca yoxlama lazımdır. Eksklüzivlik və müəllif hüququ iddia edilmir.

2026-11-25 tarixli rəsmi kataloq baxışında OpenAI `gpt-image-2.6-sunburst`, `gpt-image-2.6-flare` və 2.5 ailəsini sadalayır; Google sənədi `gemini-nano-banana-2.1` və `gemini-3-pro-image` adlarını göstərir. Bu kataloq məlumatı bu layihənin generasiya backend-ini müəyyən etmir. [OpenAI şərtləri](https://openai.com/policies/terms-of-use/) müvafiq istifadə şəraitində output hüquqlarından, unikal olmamaqdan və üçüncü tərəf məsuliyyətindən bəhs edir; [Gemini API şərtləri](https://ai.google.dev/gemini-api/terms) Google-un output sahibliyi iddia etməməsini və istifadəçi məsuliyyətini bildirir. Bunlar Arena alətinə hansı müqavilənin tətbiq edildiyini sübut etmir.
