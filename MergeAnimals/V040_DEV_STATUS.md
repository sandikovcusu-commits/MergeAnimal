## Ölçü və export
V0.3 gameplay heyvanları üçün ayrıca texture qovluğu 0 byte idi (vektor fallback). Hazırkı 10 PNG `assets/animals/` diskinə təxminən 3,007,838 byte, 3 SVG fon təxminən 3,446 byte əlavə edir (qovluq metadata daxil ola bilər). 10 ədəd 512×512 RGBA üçün sadə, mipsiz nəzəri GPU əsas səviyyə 10×512×512×4 = 10,485,760 byte (~10 MiB), mipmap varsa təqribən 13.33 MiB; faktiki import formatı/GPU ölçülməyib və VRAM compression fərqli ola bilər. `art_source/`, `concepts/`, `art_reports/` `.gdignore` ilə importdan xaricdir; export preset və Web export yoxlanmadığından faktiki export paketi təsdiqlənməyib. PNG/fonların aktiv seçilib seçilməməsi, tam Windows/Web və mobil touch/CPU/FPS/enerji sahədə sınağı aparılmayıb.
