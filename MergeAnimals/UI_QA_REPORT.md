# UI/UX QA — V0.5.0 DEV

## Status / coverage
Baseline `1bc53c3` was rerun before changes: [45686946595](https://github.com/sandikovcusu-commits/MergeAnimal/actions/runs/45686946595), 49 + 61 + 64 + 53 = **227 DEV assertions**, no failures. Release acceptance separately remained blocked (24 missing expressions and rights review). Code remains based on that project; physics parameters were not changed.

The entry point is now `scenes/ui/MainMenu.tscn`: Play actually changes to `Game.tscn`; Collection and Challenges are explicitly disabled and marked as future work. Best score comes from the existing score file. The heading is a code-drawn English wordmark, not a finished standalone logo. Pause opens Resume, Restart, Settings and Main Menu; game over shows final/best, largest level, merge count and max combo with Restart/Main Menu. No false Continue/ad control is shown. Settings use a separate `user://wild_garden_settings.cfg`, persisted sliders, mute, reduced effects, language, and replay tutorial; Music/SFX buses exist but no music or effect audio files have been supplied.

A first-run tutorial forces the first two animals to match only in tutorial mode; player controls the drop. Hints advance after drag, first drop, second drop and a real merge, ending with a danger-line reminder. Skip persists; replay is in Settings. It is not a timed human comprehension study. During normal play RNG/spawn weights are unchanged. Reduced effects suppresses the extra effects; the lightweight burst remains. Six kinds are generated procedurally and removed after playback; no additional large textures. Only play, pause, restart, settings, home, back, collection and challenge icons are currently connected (the last two disabled); the full 20-icon integration remains incomplete. Four-language dictionaries are partial: in particular animal names, wordmark, debug and some game text are not localized. Screen layouts in AZ/TR/RU have not been visually verified.
