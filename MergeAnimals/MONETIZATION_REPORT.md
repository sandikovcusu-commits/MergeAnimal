# Monetizasiya — yoxdur

CrazyGames SDK və reklam kodu yoxdur; reklam və gəlir təsdiqlənməyib. Basic Launch üçün reklamlar platforma tərəfindən deaktivdir. Nəşr, hesab yaradılması, ödəniş və ya kommersiya istifadəsi edilməyib. Mövcud sprite-ların kommersiya hüquqları təsdiqlənməyib. İstənən seçimli rewarded reklam və limitsiz olmayan pulsuz power-up-ların qorunması yalnız gələcək B mərhələsində ayrıca implementasiya və sınaqdan sonra qiymətləndirilə bilər.
