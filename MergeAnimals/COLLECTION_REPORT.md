# V0.6.2 — Animal Collection

The Main Menu opens a 3-column, 12-card scrollable collection with existing animal sprites, level, lock state, count, first discovery date, description, progress bar, details and Back. Locked animals use the existing sprite as a dark silhouette and the existing lock SVG. Details show the stored date and count. Names, descriptions and collection controls are available in EN/AZ/TR/RU.

## Discovery rule
- A genuine successful drop of tiers 1–5 creates one animal: it increments that tier's creation count and unlocks it on the first occurrence. Mouse has only this route. For tiers 2–5 a genuine merge result is also counted. Tiers 6–12 are created and discovered only by a successful merge of the previous tier.
- The first creation stores the local device date/time and queues one nonblocking, auto-closing sprite notification. Repeated creation increases the count but does not replace the date or create another discovery notification. Several discoveries are shown sequentially; reduced-effects mode removes the fade.
- Debug controls mark the session tainted; their bodies and descendants do not grant discoveries. Restore/load and plain `create_animal` fixtures do not grant discoveries. Normal dropped bodies are marked eligible; a merge result is eligible only if both parents were eligible. Golden Merge does not create or delete a collection entry.
- V0.6.1 bodies lack provenance. They are conservatively restored as ineligible: merging one cannot grant a speculative discovery. New genuine drops and eligible merges are still tracked. Counts/dates from before this version cannot be reconstructed; no historical discovery is invented.
