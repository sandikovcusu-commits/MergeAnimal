# V0.6.2 — Player Statistics

The Statistics screen reads local saved values, not sample values. It shows total games, games completed by Game Over (restart/abandon is not a completed game), genuine drops, eligible merges including Golden, best score, highest discovered tier, maximum combo, Golden Merge count, active play time, discovered count/completion and all 12 creation counts.

A new Classic game increments total games; Continue restores the existing game without incrementing it. Play time accumulates only while gameplay is running, not during pause, menu or collection. Normal drops and eligible merge results feed the same creation counts as the collection; Golden removes two board bodies but never subtracts discovery counts. Debug control use taints that session and suppresses subsequent drop/merge/discovery statistics; an ineligible/legacy-provenance merge marks the session score untrusted so it cannot create a false lifetime score or combo record, while later genuine drops/eligible animal creations are still counted. Best Score keeps the pre-existing V0.6.1 best where available.

A resumed V0.6.1 session is counted as one known in-progress game on migration. Older lifetime games, drops, merges, play time and discovery history were not stored and cannot be inferred, so they start at zero; prior best, settings and current session are retained. Session and lifetime data are checkpointed together: restoring the checkpoint does not independently replay counters. Losing the latest checkpoint can roll both back. For a future Undo feature, decide whether permanent discoveries/stats survive undo; if they do, introduce stable per-session event IDs and an idempotent committed-event ledger. Undo is not implemented or implied here.
